# Fonts

All files here are EB Garamond (Georg Duffner, Octavio Pardo), licensed under the
SIL Open Font License 1.1 (see OFL.txt).

- `EBGaramond-Regular/Italic/SemiBold.woff2`: subset (Latin) from the CTAN `ebgaramond`
  package, https://ctan.org/pkg/ebgaramond
- `EBGaramond-InitialsF1.woff2` (embellishment layer) and `EBGaramond-InitialsF2.woff2`
  (letter layer): the full A–Z ornate initials. The upstream EB Garamond Initials font only
  covers ten letters; the complete alphabet was drawn for turntrout.com and published in
  https://github.com/alexander-turner/TurnTrout.com (quartz/static/styles/fonts/EBGaramond).
  Used here as an OFL derivative work, subset to A–Z.

Rebuild with `scripts/build_fonts.sh`.
